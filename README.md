# Finance Pro

Base inicial do aplicativo financeiro moderno em React, TypeScript, Vite, TailwindCSS,
React Router, React Query e Supabase.

## Como executar

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run lint
npm run build
npm run format:check
```

## Variaveis de ambiente

Copie `.env.example` para `.env.local` e preencha quando a integracao com Supabase for
implementada.
